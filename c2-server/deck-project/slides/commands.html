OPERATOR REFERENCE

Implant Command Reference

Command What it does
processes List running processes
closeproc <name.exe> Kill a process by name
screenshot Capture screen → upload to C2
dir show <C:\Path> List directory contents
dir read <C:\file.txt> Read file contents
system <cmd args> Run via cmd.exe (blind)
run <path> [args] Execute a file
loader <url> <dest> Download file to target
Command What it does
inject_dll <proc> <dll> DLL injection into process
inject_shell <proc> <sc> Shellcode injection
service show List device drivers/services
filecrypt <path> <key> AES-encrypt a file
filedecrypt <path> <key> AES-decrypt a file
botnet start <url> Start HTTP flood thread
botnet stop Stop flood thread
close Terminate implant process

Commands are issued from the admin dashboard → sent to bot → result returns on next beacon tick

For the demo: use "processes" first (safe, informational), then "screenshot" to show the upload flow. Avoid inject or botnet in a live demo unless specifically asked.
