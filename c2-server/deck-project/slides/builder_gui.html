What Each Field Means

C2 Configuration

C2 Host

Your server's hostname or IP. Must match the CN in your TLS certificate exactly.

e.g. c2.redteam.local or 192.168.1.5

Auth Key

Secret shared with the C2 server. Set the same value in C2_AUTH env var on the server.

Payload Settings

Output filename

Name of the generated .exe

Beacon interval (ms)

How often the stub polls for commands. 5000 = 5 sec.

Persistence (optional)

Add registry autorun entry

Adds HKLM Run key so stub starts on Windows boot. Autorun entry name = the registry value name.

Add scheduled task

Creates ONLOGON task in Task Scheduler. Task name = the display name in taskschd.msc.

Delivery

Drop && run

Copies itself to Drop path, runs from there, optionally auto-deletes the original.

Watchdog copy path

Where the stub copies itself to run the anti-analysis watchdog process.

Click "Test C2 Server" before building — confirms server is reachable and auth key is correct
