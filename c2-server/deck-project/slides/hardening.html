SECURITY HARDENING

Defense Against Analysis & Interception

Config Encryption

C2 hostname encrypted with AES-128 CBC. Random IV per build — no two payloads produce same ciphertext.

AES-128 CBC + random IV

XOR Obfuscation

Full config blob XOR'd. Key derived from first 1024 bytes of the binary itself — no static key string exists in the file.

8-byte magic marker

Cert Pinning

Every HTTPS call validates the cert: CN must match the C2 host AND cert must be self-signed. CA-signed proxy certs are rejected.

Blocks TLS inspection

Anti-Debug

Checks IsDebuggerPresent and CheckRemoteDebuggerPresent on startup. ExitProcess(0) if detected.

WinAPI debug checks

Tool Detection

Scans 29 analyst tool process names + EnumWindows scan for Wireshark, IDA, Fiddler, x64dbg, ProcHacker window titles.

29 processes + window scan

In-House Exfil

Screenshots multipart-POST directly to /upload. No prntscr.com. Files land in uploads/ on your server.

Zero third-party traffic

All hardening is togglable via Builder checkboxes where applicable
