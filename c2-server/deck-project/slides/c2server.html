C2 SERVER

Custom Backend — How It Works

API Endpoints

Route Purpose
GET /ping Builder connectivity test
GET /checkin Bot registers, sends system info
GET /cmd Poll for next command (consumed on read)
GET /result Bot returns command output
POST /upload File / screenshot upload (multipart)

Auth: every request requires

?auth=<AUTH_KEY>

Set via environment variable C2_AUTH

Admin Dashboard Features

  • Live bot list — ID, last seen, system info
  • Send commands to any bot
  • View command results per bot
  • Browse uploaded screenshots / files
  • Auth-gated — password required to access

TLS Requirement

openssl req -x509 -newkey rsa:2048
-keyout key.pem -out cert.pem
-days 365 -nodes -subj "/CN=c2.host"

CN must match the C2 Host field in Builder

Runs on Node.js (Express) · Port 443 default · Self-signed TLS required for cert pinning
